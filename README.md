# عيادة سوا التدريبية

لعبة تدريب للأخصائيين النفسيين على الوصول للتشخيص في حالات الأطفال والمراهقين، مبنية على دليل "تدريب سوا للأطفال والمراهقين".

- `docs/index.html`: اللعبة (شاشات الأخصائي + داشبورد المشرفة)
- `docs/cases.js`: الـ12 حالة. ممكن تتعدل من غير ما تلمس كود اللعبة
- `firestore.rules`: قواعد أمان قاعدة البيانات
- `SETUP.md`: خطوات تشغيل الموقع المستقل (Firebase + GitHub Pages)
- `prototype/mockup.html`: النموذج المبدئي للشكل

من غير إعدادات Firebase، اللعبة بتشتغل في وضع تجربة على جهاز واحد، والبيانات بتتحفظ في المتصفح بس.
