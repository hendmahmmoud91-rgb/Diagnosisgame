# عيادة سوا التدريبية

لعبة تدريب للأخصائيين النفسيين على الوصول للتشخيص في حالات الأطفال والمراهقين، مبنية على دليل "تدريب سوا للأطفال والمراهقين".

- `game/index.html`: اللعبة (شاشات الأخصائي + داشبورد المشرفة)
- `game/cases.js`: الـ12 حالة. ممكن تتعدل من غير ما تلمس كود اللعبة
- `prototype/mockup.html`: النموذج المبدئي للشكل

لو اتفتحت اللعبة برا Claude، بتشتغل في وضع تجربة على جهاز واحد، والبيانات بتتحفظ في المتصفح بس.
